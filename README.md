# Personal Portfolio Website

[🌐 **View Live Website**](https://mwallis45.github.io/My-Portfolio/)

A central hub showcasing software, digital signal processing (DSP), and audio engineering projects. Built and hosted using **GitHub Pages**.

---

## Overview

This repository contains the source code for the landing page and core routing of my personal portfolio. 

* **Visual Demos:** Provides accessible, interactive demos, media, and project overviews for non-technical visitors.
* **Modular Structure:** Each featured project links to its corresponding repository, documentation, or live demo.
* **Integrated Documentation:** Synthesizes key details from individual project `README` files with extended media and audio samples.

---

## Tech Stack

* **Hosting:** GitHub Pages
* **Frontend:** HTML5, CSS3, JavaScript

---

## Local Setup & Customization

If you would like to use this layout as a template for your own portfolio:

1. Clone the repository:
   ```bash
   git clone [https://github.com/mwallis45/My-Portfolio.git](https://github.com/mwallis45/My-Portfolio.git)
   ```
2. Open index.html in any modern web browser to preview locally.
3. Update project links and assets in the root directory to point to your own repositories.
